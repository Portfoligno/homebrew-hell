# homebrew-hell

Homebrew tap for [Hell](https://github.com/chrisdone/hell), a Haskell-based shell scripting language.

Pre-built binaries for macOS (ARM and Intel).

## Install

```
brew install Portfoligno/hell/hell
```

## Upgrade

```
brew upgrade hell
```

## How it works

Upstream releases are detected daily. When a new tag appears on `chrisdone/hell`, CI automatically builds macOS binaries, creates a release, and updates the formula. No manual intervention required.
